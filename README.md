# TOYLEK STUDIO

Android-приложение для планшетов: гости записывают видео-поздравления и делают фото на свадьбах, днях рождения и других мероприятиях. Интерфейс полностью на русском, работает без интернета.

## Как получить APK

Проект написан полностью, но в среде, где он создавался, не было Android SDK и доступа в интернет, поэтому Gradle-сборка там не запускалась. Соберите APK одним из способов ниже.

### Вариант 1. GitHub Actions (без установки программ)
1. Создайте пустой репозиторий на github.com (можно приватный).
2. Загрузите в него содержимое этой папки: кнопка **Add file → Upload files**, папку `.github` тоже нужно загрузить.
3. Откройте вкладку **Actions** → «Сборка APK». Сборка запускается сама после загрузки, её можно запустить и вручную кнопкой **Run workflow**.
4. Через 5–10 минут скачайте архив **TOYLEK-STUDIO-APK** внизу страницы сборки. Внутри:
   - `TOYLEK-STUDIO-debug.apk` — устанавливается всегда;
   - `TOYLEK-STUDIO.apk` — оптимизированная версия (меньше размер).

### Вариант 2. Android Studio
1. Установите Android Studio (Ladybug 2024.2 или новее).
2. **File → Open** → выберите папку `ToylekStudio`, дождитесь синхронизации Gradle.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Либо запустите `build-apk.bat` (Windows) или `./build-apk.sh` (macOS/Linux). Готовые APK появятся в папке `output`.

### Установка на планшет
Скопируйте APK на планшет и откройте его. Разрешите установку из этого источника, если Android спросит.

## Возможности

| Раздел | Что умеет |
|---|---|
| Видео | Передняя и задняя камеры, запись со звуком, таймер «00:00 / 05:00», автоостановка (от 1 до 5 минут, настраивается), предупреждение за 15 секунд до конца |
| Фото | Обратный отсчёт 3/5/10 секунд, вспышка экрана, переключение камер |
| Редактор | 14 шрифтов с кириллицей, размер и 24 цвета текста, тень и контур, несколько надписей, перетаскивание пальцем, 13 шаблонов (свадьба, день рождения, юбилей, кинолента, полароид и др.), фон из галереи или готовые градиенты. Работает и для фото, и для видео (надписи накладываются на всё видео, звук сохраняется) |
| Галерея | Разделы «Фото» и «Видео», просмотр, листание, подписи, удаление, выбор нескольких файлов |
| Сохранение | Автоматически в галерею Android: `Pictures/TOYLEK STUDIO` и `Movies/TOYLEK STUDIO`. Оформленная версия сохраняется отдельным файлом, оригинал остаётся |
| USB-флешка | «На флешку» → системный файловый менеджер → выбрать флешку. Создаётся папка `TOYLEK STUDIO/<дата>/Фото, Видео` и файл `Подписи.txt` |
| Киоск | Закрепление приложения на экране, блокировка кнопки «Назад», вход в настройки и удаление файлов только по PIN-коду |
| Надёжность | Автовозврат на главный экран при бездействии, экран «Спасибо», экран не гаснет, проверка свободной памяти, журнал сбоев и автоперезапуск в режиме киоска |

## Настройки и режим киоска
- Вход в настройки: значок шестерёнки или 5 быстрых нажатий / долгое нажатие на надпись «TOYLEK STUDIO» в левом верхнем углу.
- **PIN-код по умолчанию: 1234.** Смените его перед мероприятием.
- В режиме киоска Android один раз попросит подтвердить закрепление экрана.
- Полная блокировка без подтверждений: на сброшенном планшете без Google-аккаунтов выполните
  `adb shell dpm set-device-owner com.toylek.studio/.kiosk.KioskAdminReceiver`.

## Архитектура
Kotlin, Jetpack Compose (Material 3), CameraX 1.4, Media3 Transformer (наложение на видео), Coil (миниатюры). minSdk 26, targetSdk 35.

```
domain/      модели и интерфейсы репозиториев (без зависимостей от UI)
data/        MediaStore, настройки, экспорт на USB, CameraX, отрисовка оформления, обработка видео
di/          ручное внедрение зависимостей
kiosk/       режим киоска и администратор устройства
ui/          экраны Compose: главный, камера, просмотр снятого, редактор, галерея, настройки
```

Шрифты распространяются по лицензии SIL Open Font License (тексты лицензий в `fonts-licenses`), кроме FreeSerif (GNU FreeFont, GPL с исключением для шрифтов).
